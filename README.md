# 🏨 Hotel Inventory

![Angular](https://img.shields.io/badge/Angular-20-red?logo=angular)
![TypeScript](https://img.shields.io/badge/TypeScript-blue?logo=typescript)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5-purple?logo=bootstrap)
![License](https://img.shields.io/badge/License-MIT-green)

A modern Hotel Inventory Management application built with **Angular**. This project is part of my Angular learning journey, where I explore Angular fundamentals, component architecture, data binding, routing, services, dependency injection, and best practices while building a real-world application.

## 🚀 Features

- Display hotel room inventory
- View room details
- Select rooms using parent-child communication
- Dynamic data binding
- Conditional rendering
- Event handling with `@Output` and `EventEmitter`
- Responsive UI with Bootstrap
- Angular Standalone Components
- Modern Angular Control Flow (`@if`, `@for`)
- Change Detection examples
- Component communication using `@Input` and `@Output`

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/HotelInventory.git
```

Navigate to the project

```bash
cd HotelInventory
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
ng serve
```

Open your browser at:

```
http://localhost:4200
```
